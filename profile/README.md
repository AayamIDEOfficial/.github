AayamIDE
==========

Welcome to AayamIDE!

AayamIDE is an Integrated Development Environment (IDE) for Android devices to develop Android applications.

### Repository info
- [AayamIDE](https://github.com/AayamIDEOfficial/AayamIDE) - The main application.
- [aayamide-tools](https://github.com/AndroidIDEOfficial/androidide-tools) - Build tools for AayamIDE (Android SDK).
- [terminal-packages](https://github.com/AndroidIDEOfficial/terminal-packages) - Fork of [termux-packages](https://github.com/termux/termux-packages) for AayamIDE Terminal.
- [nb-javac-android](https://github.com/AndroidIDEOfficial/nb-javac-android) - The Java Compiler used in AayamIDE (ARCHIVED).
- [android-tree-sitter](https://github.com/AndroidIDEOfficial/android-tree-sitter) - Android Java Bindings for the tree-sitter library. Used in AayamIDE for syntax highlighting.
- [tree-sitter-*](https://github.com/orgs/AndroidIDEOfficial/repositories?q=tree-sitter-&type=all&language=&sort=) - Grammars for tree-sitter.
